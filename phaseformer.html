1. 研究背景与动机

时间序列预测在金融、能源、交通等领域具有重要价值。周期性是时间序列的核心归纳偏置。

近年来，基于片段（Patch）的方法（如 PatchTST、Crossformer）通过将序列切分为片段令牌（patch tokens）来利用周期性，取得了良好的预测效果。然而，这些方法存在两个严重问题：

  1. 效率低下：参数量大、计算成本高，难以扩展到大规模、复杂数据集。
  2. 对周期漂移敏感：真实场景中周期模式会因外部因素（新道路、作息调整等）发生漂移，导致：
    • 需要高维表示空间适应分布变化 → 参数膨胀
    • 难以泛化到训练分布之外的样本 → 预测不可靠

核心问题：如何设计既高效又鲁棒、能应对周期漂移的时序预测模型？

2. 核心洞察（Motivations）

论文通过可视化和理论分析，对比了 Patch 令牌 与 Phase 令牌 的几何结构，得出两个关键洞察。

洞察 1：相位令牌全局平稳，片段令牌仅局部平稳

  • Patch 令牌：由局部周期内的连续观测组成。
    • t-SNE 显示分布随时间漂移（局部平稳，全局漂移）
    • 不同周之间的 MMD 距离大 → 分布差异大
  • Phase 令牌：跨周期固定相对位置的观测组成。
    • t-SNE 显示形成紧凑、稳定的簇
    • MMD 距离显著更小 → 全局平稳

结论：相位令牌的分布漂移更小，有利于在时间轴上泛化。

洞察 2：相位令牌位于低维子空间

  • PCA 分析：
    • 2 个主成分即可解释 Phase 令牌 90% 以上方差
    • Patch 令牌需要 11+ 个主成分才能达到同等解释度
  • 理论证明（Theorem 1）：
    • Phase 令牌化在周期模式变化（线性变换）下具有结构不变性，仅受噪声扰动
    • Patch 令牌化会产生不可消除的结构偏移

结论：相位信息本质低维 → 可以用极小的参数量和计算量高效建模。

3. 模型设计：PhaseFormer

PhaseFormer 将时间序列从逐步预测转化为逐相位预测，核心流程如下。

3.1 数据预处理

  • 归一化：RevIN（Kim et al., 2021）
  • 相位令牌化：
    • 估计周期长度 \(L_{\text{phase}}\)（自相关分析）
    • 将输入序列循环填充至 \(P_{\text{in}} \times L_{\text{phase}}\)
    • 重塑为相位-周期矩阵 \(\mathbb{R}^{L_{\text{phase}} \times P_{\text{in}}}\)
  • 相位去令牌化：逆操作恢复预测序列

3.2 模型架构

  1. 嵌入层
    线性投影：\(\mathbf{Z} = f_\theta(\mathbf{X}_{\text{phase}}) \in \mathbb{R}^{L_{\text{phase}} \times d}\)，添加可学习的位置编码。
  2. 跨相位路由层（替代全注意力）
    • 引入 \(M\) 个可学习的路由器 \(\mathbf{R} \in \mathbb{R}^{M \times d}\)
    • Phase → Router：路由器作为 Query，相位作为 Key/Value，通过交叉注意力聚合信息
    • Router → Phase：相位作为 Query，路由器作为 Key/Value，分发信息
    • 复杂度 \(O((L_{\text{phase}}+M)d^2 + M L_{\text{phase}} d)\)，远低于自注意力的 \(O(L_{\text{phase}}^2 d)\)
  3. 共享预测器
    所有相位共享同一个线性层 \(g_\phi: \mathbb{R}^{d} \to \mathbb{R}^{P_{\text{out}}}\)，输出预测的相位-周期矩阵 \(\mathbf{Y}_{\text{phase}}\)。

3.3 复杂度分析

  • 整体复杂度与输入/输出长度线性相关
  • 参数量仅约 1k，FLOPs 相比 PatchTST/Crossformer 减少 99.99%

4. 实验

4.1 数据集

  • ETT（电力变压器温度）：4 个子集
  • Weather（天气）
  • Electricity（电力消耗）
  • Traffic（交通流量）

4.2 对比基线

  • Patch-based：PatchTST, Crossformer, TimeMixer
  • Phase-based：SparseTSF, TimeBase
  • 频域：FEDformer, FITS
  • 其他：iTransformer

4.3 预测精度

数据集PhaseFormer 表现
Traffic最佳，MSE 0.386（超 PatchTST 6.3%）
Electricity最佳或次佳
Weather最佳
ETTh2仅次于 FITS
  • 在大型、复杂数据集上优势尤其明显
  • 唯一弱项是 ETTh2（周期相对固定，简单数据集），但仍保持强竞争力

4.4 效率对比

  • 参数量：PhaseFormer ≈ 1k，PatchTST ≈ 100k–1M
  • FLOPs：PhaseFormer 在 Traffic 上比 PatchTST 低 4 个数量级

4.5 消融实验

  • 路由数 \(M\)：\(M=4\) 或 \(8\) 最佳，远小于相位总数 \(L_{\text{phase}}=24\)，证实低维特性
  • 跨相位路由 vs. 全注意力 / 线性混合 / 无路由：
    • 全注意力：精度略低 + 计算成本高
    • 线性混合 / 无路由：精度显著下降
    • → 路由机制同时保证了效率和精度

4.6 案例分析

  • 注意力权重显示：相邻相位倾向于分配给相同路由器 → 捕捉局部相似性
  • 不同相位（如相位 1、5、9）具有不同的注意力模式，对应不同的时间行为（平稳/周期/趋势）

5. 理论分析（Theorem 1 & 3）

设定

  • 数据矩阵 \(X = AG^\top + N\)，低秩信号 \(M = AG^\top\)，\(r \ll \min(D,H)\)
  • 周期变换：\(X' = X S^\top + R\)，\(S\) 为周期坐标变换，\(R\) 为日间扰动

结论

  1. 相位令牌化（列空间）
    • 在无噪声时严格不变
    • 有噪声时扰动上界与噪声量成正比
    • 对周期漂移鲁棒
  2. 片段令牌化（行空间）
    • 即使无噪声也会产生结构偏移 \(d_0 = d(\mathrm{Col}(G), \mathrm{Col}(SG))\)
    • 若 \(S(\mathrm{Col}(G)) \neq \mathrm{Col}(G)\)，则 \(d_0 > 0\)，无法消除

理论证明：相位方法比片段方法对周期模式变化具有本质的稳定性。

6. 优势总结

维度Patch 方法PhaseFormer
表示方式固定长度连续窗口跨周期固定相对位置
对周期漂移敏感，需学习多种变体鲁棒，结构不变性
参数规模大（100k+）极小（~1k）
计算成本高（FLOPs 大）极低（99.99% 降低）
泛化能力差（训练分布外失效）强
适用场景周期固定、局部平稳周期可能漂移、复杂大数据集

7. 局限与未来工作

  • 假设：输入/输出范围内周期局部稳定
  • 不足：高度不规则或非重复周期下，相位表示可能失效
  • 未来方向：
    • 建模非平稳性和复杂漂移
    • 发展更具弹性的相位表示
    • 将 PhaseFormer 推广为长时预测的基准

8. 个人思考

  • 本质区别：Patch 方法将"局部基准值"和"波形形态"耦合在同一 token 中，周期漂移时产生多种变体；Phase 方法解耦两者，只建模波形形态，基准值由归一化处理 → 更轻量、更稳定。
  • 工业价值：在物流调度、电力负荷、交通流量等周期可能缓慢变化的场景，PhaseFormer 提供了一种极低成本的轻量替代方案，尤其适合资源受限或高频预测任务。
  • 可迁移性：Phase 思想不仅限于时序预测，也可推广到其他具有周期结构的序列建模任务。
