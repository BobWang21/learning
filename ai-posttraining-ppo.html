1.1 PPO：工作流程与 Loss

首页 > AI > Training > 1.1 PPO

PPO（Proximal Policy Optimization）在 RLHF 中的核心作用，是用奖励模型给完整回复打分，用参考模型限制偏离，用价值模型降低方差，最后稳定地更新策略模型。

这篇按真实训练链路展开：Rollout → Scoring → Advantage → Update。

1. 系统概览：四个核心模型

训练开始前，先明确 PPO 中四个模型的职责。真正更新的是策略模型和价值模型；参考模型与奖励模型保持冻结，提供约束和评价信号。

2. 完整工作流程

1. Rollout

策略模型生成回复，并记录每个 token 的概率。

2. Scoring

奖励模型、参考模型、价值模型分别给出评分、KL 参考和状态价值。

3. Advantage

把 reward、KL、value 汇总成每个 token 的优势值。

4. Update

用裁剪目标更新 Actor，用 MSE 更新 Critic。

2.1 阶段一：数据采样（Rollout）

目标：使用当前策略模型生成一批回复数据。

  1. 从数据集中采样一批提示词 \(x \sim \mathcal{D}\)。
  2. 将 \(x\) 输入策略模型 \(\pi_\theta\)，自回归生成完整回复。
  3. 记录生成过程中每一步的对数概率。
\[ y = (y_1, y_2, \ldots, y_T) \sim \pi_\theta(\cdot \mid x) \]
\[ \log \pi_\theta(y_t \mid x, y_{

此时：只有策略模型（Actor）在工作，产出后续要被评估的一批文本数据。

2.2 阶段二：评估与打分（Scoring）

目标：利用冻结模型对生成回复进行多维度评估。

奖励模型打分

将提示词和完整回复 \((x,y)\) 输入奖励模型，得到最终奖励分数。

\[ R(x,y)=r_\phi(x,y) \]

通常只在最后一个 token（EOS）处给予奖励，中间 token 的即时奖励设为 0。

参考模型计算

计算参考模型在每一步生成同一 token 的对数概率。

\[ \log \pi_{\text{ref}}(y_t \mid x,y_{

该值用于后续 KL 惩罚，防止策略偏离 SFT 模型太远。

价值模型预估

根据提示词和已生成前缀，估计每一步的状态价值。

\[ V_\psi(s_t), \quad t=1,2,\ldots,T \]

其中 \(s_t\) 表示时间步 \(t\) 的状态，即 \(x\) 和已生成的 \(y_{

汇总到 token 级别

奖励模型给最终分，参考模型给 KL 约束，价值模型给基线。三者共同服务于下一步 Advantage 计算。

2.3 阶段三：优势值（Advantage）

目标：融合所有模型的信息，计算每个动作，也就是每个 token 的“好坏程度”。

构建 token 级别的即时奖励

先确定原始即时奖励：中间 token 为 0，最后一个 token 承接奖励模型对完整回复的打分。

\[ r_t^{\text{raw}} = \begin{cases} 0, & t

然后计算策略模型相对参考模型的 KL 惩罚：

\[ \text{kl\_penalty}_t = \beta\left( \log \pi_\theta(y_t \mid x,y_{

将原始奖励减去 KL 惩罚，得到修正后的即时奖励：

\[ \text{reward}_t = r_t^{\text{raw}} - \text{kl\_penalty}_t \]

意义：如果模型在某个 token 上偏离参考模型太远，即使最终总分很高，中间步骤也会被扣分，从而抑制过度优化。

计算折扣回报 \(G_t\)

从时间步 \(t\) 开始累计未来奖励，并用折扣因子降低远期奖励权重。

\[ G_t = \sum_{k=0}^{T-t} \gamma^k \cdot \text{reward}_{t+k} \]

其中 \(\gamma \in (0,1]\)，通常取 0.99。

用 GAE 计算优势值 \(A_t\)

优势值衡量的是：在状态 \(s_t\) 下生成 token \(y_t\)，比价值模型原本预期的平均水平好多少。

\[ \delta_t = \text{reward}_t + \gamma V_\psi(s_{t+1}) - V_\psi(s_t) \]
  • 如果 \(\delta_t>0\)，实际结果优于预期，这个动作是“惊喜”。
  • 如果 \(\delta_t<0\)，实际结果差于预期，这个动作是“失望”。

将多个时间步的 TD 误差进行指数加权求和，得到最终优势值：

\[ A_t = \sum_{l=0}^{T-t}(\gamma\lambda)^l\delta_{t+l} \]

其中 \(\lambda\in[0,1]\)，通常取 0.95，用来控制偏差与方差的权衡。

到这里：奖励模型提供最终 \(R\)，参考模型提供 KL 惩罚，价值模型提供基线 \(V\)，共同得到每一步的优势值 \(A_t\)。

2.4 阶段四：模型更新（PPO Update）

目标：利用计算好的优势值，更新策略模型和价值模型。

更新策略模型 Actor

让好动作 \((A_t>0)\) 更可能发生，让坏动作 \((A_t<0)\) 更不可能发生，同时限制单次更新幅度。

\[ \rho_t(\theta)= \frac{\pi_\theta(y_t\mid x,y_{
\[ L^{\text{CLIP}}(\theta)=\mathbb{E}_t\left[ \min\left( \rho_t(\theta)A_t, \operatorname{clip}(\rho_t(\theta),1-\epsilon,1+\epsilon)A_t \right) \right] \]
\[ \theta \leftarrow \theta + \alpha\,\nabla_\theta L^{\text{CLIP}}(\theta) \]

更新价值模型 Critic

让价值模型的预测更接近实际折扣回报，使其成为更好的基线。

\[ L^{\text{VF}}(\psi)=\mathbb{E}_t\left[(V_\psi(s_t)-G_t)^2\right] \]
\[ \psi \leftarrow \psi - \alpha\,\nabla_\psi L^{\text{VF}}(\psi) \]

裁剪直觉：好动作最多把概率增大到 \(1+\epsilon\) 倍；坏动作最多把概率减小到 \(1-\epsilon\) 倍。这个约束是 PPO 稳定性的关键。

3. 多模型协同

可以把 PPO 看成一条分工明确的数据链：

Actor 写作文

策略模型根据 prompt 生成完整回复，并记录生成概率。

Reward 打总分

奖励模型像阅卷老师，对完整回复给出 \(R(x,y)\)。

Reference 扣偏离分

参考模型像标准范文，偏离过大时通过 KL 惩罚扣分。

Critic 做预判

价值模型像助教，预测每个状态之后大概能拿多少分。

优势值就是“实际表现 + 下一步预期”相对“当前预期”的偏差，它告诉策略模型：刚才生成的 token 到底比预想更好还是更差。

4. PPO Loss

4.1 总目标

PPO 同时做两件事：策略模型做梯度上升，最大化裁剪后的策略目标；价值模型做梯度下降，最小化价值预测误差。

\[ \boxed{ \begin{aligned} &\max_\theta\;\mathbb{E}_t\Big[ \min\big(\rho_t(\theta)A_t,\operatorname{clip}(\rho_t(\theta),1-\epsilon,1+\epsilon)A_t\big) \Big]\\[10pt] &\min_\psi\;\mathbb{E}_t\Big[(V_\psi(s_t)-G_t)^2\Big] \end{aligned} } \]
